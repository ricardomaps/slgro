# slgro

slgro is a floating (with keyboard-driven window movement, resizing and added centering and snapping) window manager for swc

This wm is a fork of tohu (https://git.sr.ht/~shrub900/tohu) which in itself is also a fork of wsxwm (https://git.sr.ht/~uint/wsxwm) go check both projects out!! Without the both of them slgro wouldn't exist!! ^^

As of writting this, the project is still very experimental, i will try to fix some of it's current flaws and clean up some stuff during the next following days, im just proud i made something somewhat useful that fits my needs :3

slgro can be found on:
- Codeberg (the "main" repository) : https://codeberg.org/0uppy/slgro
- My personal Forgejo (where updates are pushed to Codeberg) : https://git.ouppyawa.xyz/0uppy/slgro
